## Inclusion discipline

1. Cite **exact branches**, not only a default README, where experiments live.
2. No donor project automatically becomes part of MSyoU; this repository contains a **new, minimal independent demo**, not a code transplant.
3. Every candidate integration requires fresh inspection of license, tests, inputs, API contracts, privacy, and authority boundary.
4. HOLD is a useful outcome. A missing observation is not proof of failure, and a beautiful rendering is not an authentic signed event.
5. A contact with a university staff member remains a **conversation between individuals**, unless an institution separately authorizes an engagement.
