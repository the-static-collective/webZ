# THE MISSING INGREDIENT — LemonPRESS × Nourish × Kinship × Jubilee (Field 001)

An **executable, fictional community-food circular**. A recipe finds a specific shortage; explainable matching presents synthetic candidate offers; two simulated participant roles step through proposal → acceptance → reported completion → separate recipient acknowledgement; the outcome changes a printable one-page edition and a 20–40-second draft radio script. A separate issue can then begin.

**Status:** reviewable working prototype, NOT a grocery, resource registry, donation platform, broadcaster, hosted contact system, or actual donor-project integration. This independent Static Collective work is not authorized by the Waseca grocery organizers, Coalition of Care, Real Life Covenant Church, Kinship, or any other institution.

## Run
The project is 100% static and dependency-free.

- Open `index.html` through a local static server, for example from the webZ root: `npm run serve` then `http://127.0.0.1:8080/field/missing-ingredient/`.
- Tests: `node --test field/missing-ingredient/tests/engine.test.mjs` (also picked up by webZ's `npm test` via `tests/missing-ingredient.test.mjs`).

## Honest behavior

1. **Nourish-derived pantry discipline:** `have`, `missing`, and `unknown` are separate. Changing serving counts invalidates the sample proposal. Unit/quantity mismatches don't silently fit.
2. **JAR;VIS-style candidate inspection:** deterministic, explained proposals from a fixed **fictional** basket. No search for actual persons, no AI recommendations, no backend.
3. **Jubilee / Full Measure boundaries:** proposed ≠ accepted ≠ reported ≠ confirmed. User deliberately role-plays helper and recipient sequentially in one browser; the result is **not independent verification**, an earned Deed, a credit, a grant or a claimed delivery.
4. **LemonPRESS:** print-only CSS builds a recipe/question/status circular. The original source and edition remain distinct; opening a new issue does not establish prior truth.
5. **Kinship / Static Live concept:** the fictional station script is text-only. No streaming, recording, station partnership, or API calls.
6. **GrO:** an attributed result might eventually open another local possibility. This first proof only offers a **new issue** button; no game scores or geographic rewards.
7. **reLATTE-inspired:** the local receipt tape keeps stage distinctions. It's plain browser JSON, not signed, multi-party, tamper-proof, or authoritative.
8. **Table & Road:** shareable link carries only `recipe` and `issue`, never offers, messages, event history, private margin or user identity.

Everything operates in-browser and saves this fiction-only rehearsal to localStorage when permitted; no analytics, API, account, payment, inventory, remote messaging, or radio. The unstructured private margin is intentionally excluded from radio/export/link, but is stored in that browser until cleared. Protect physical food safety and personal information in any later authorized real-world pilot.
