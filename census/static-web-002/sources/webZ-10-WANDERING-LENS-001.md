# WANDERING-LENS-001 — The Miracle Automaton asks

An exploratory world lab in WebZ. The existing Sanctuary/Orchard world manifests, owner decisions, and crossing model remain unchanged. The lab is NOT a sovereign door or an assertion about a real historical event.

## Run

On the experimental branch with Node.js 22 or newer: npm test; npm run serve. Open http://127.0.0.1:8080/worlds/wandering-lens/ on that machine. A discovery link is also present on the WebZ landing page.

## Load your original media locally

The user-supplied illustration and Jubilee Engine / Thread Anchor soundtrack are NOT copied to the public GitHub repository. Use the two explicit file selectors to supply them directly in a browser tab. Local image rendering uses an object URL; local audio plays only when the browser's native audio controls are manually activated. Switching worlds, questions, and audio cues never starts playback.

The selection panel reports whether the locally selected bytes match the previously supplied original source hashes, as byte-identity checks only: illustration SHA-256 98bc094c7dc721f3f0e642966c672ed97a1ac06b67f8174e3aa0a8afa0f11e0d; audio SHA-256 f2fa58dae7ceddf0ee90e2d9dd3b0c6a4a65b46aa0a2e44231d5095bf18774ac. Matching checksums do not establish creator identity, publication rights, or historical provenance.

No upload endpoint, streaming, audio retransmission, microphone permission, external AI API, background GHoT compute, donation or content scraping is implemented. The first-party offline cache includes only WebZ code and HTML/CSS; it never caches either original media file, imports, drafts, visitor reflections, or user-generated JSON files.

## Spatial grammar

Eleven author-proposed object positions attach to the existing illustrative scene, without turning it into an evidence wall. Up/down selects one particular. Left/right adjusts image granularity. Enter stores the live dial pair as an exact nested address segment and resets to the center. Rise restores parent dials. Root returns to the founding room. The URL hash persists only the positional address, such as MWF1/t06g06/t09g03, not user answers or media file contents.

Exact nested base-eleven cell fractions use BigInt. At more than eleven nested levels or insufficient floating resolution, the companion Mandelbrot renderer explicitly displays a precision HOLD. Mathematical proximity is not evidence that anything in the illustration is historically or causally related.

## Miracle Automaton as a bounded question organ

Each particular proposes one editorial question. The machine does not supply its own answer, generate alleged facts, or interpret the song's AI-directed lyrics as instruction. The visitor can write and independently click Hold reflection locally. The immutable entry retains the exact address, original prompt, selected particular, bounded visitor text, and explicit labels REFLECTION_HELD / VISITOR_LOCAL_TEXT / UNVERIFIED_VISITOR_REFLECTION.

Answers remain in page memory by default and disappear on reload. To preserve them, user must explicitly review and download the private JSON export. Its SHA-256 check detects accidental modification but is not a cryptographic identity signature. Import is previewed and requires an explicit separate Restore action; it triggers no navigation, playback or cross-world movement. The user may erase in-memory reflections.
