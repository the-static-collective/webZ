GIVING TREE / MANUAL HANDOFF 002
Leave a seed.
Let somebody change it.
The tree has no server or shared public board yet. But you can hand a locally verified packet to somebody else. They can inspect it, add a new observation, and carry the next generation onward. Nobody needs an account.
A hash checks accidental changes to the packet; it does not authenticate authors, ownership, consent or copyright. Nothing is sent when you press Download.
