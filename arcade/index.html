HOW THE MACHINE WORKS

Real learning.
Real boundaries.

LEARN. A three-nearest-neighbors (k-NN) classifier uses your accepted examples. Each guess lists the actual examples it relied on.

SCOUT. The idle loop makes new predictions but never invents truth. You review it before it learns.

ROUTE. Community matches are synthetic examples. Exported packets say HOLD, carry their evidence, and claim no consent, sending, or completed outcomes.

OWN. Progress stays in this browser's local storage when available. Reset wipes it. No server is contacted for gameplay. The optional p5.js visual library loads from a public CDN when online.
