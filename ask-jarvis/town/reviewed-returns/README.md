# Approved anonymous field-return candidates

**There are zero real entries initially.**

This directory is an **operator-reviewed publication gate**, not a public submission inbox. No browser automatically writes here. A visitor may voluntarily share the separate anonymous \`free-graph.packet/v0\` candidate generated by their Ignition Desk with a responsible reviewer. Their private note must not be committed.

For each future publication, the reviewer must inspect the candidate's content hashes, private-source redaction and public-safety characteristics; get explicit agreement from the person sharing the information; confirm the claimed third-party work is not represented as verified; and submit a reviewed PR with a new \`<id>.json\` entry containing:

\`\`\`json
{
  "schema": "abundent/reviewed-return-entry-v1",
  "graph": { "schema": "free-graph.packet/v0", "...": "exact exported unsigned candidate graph" },
  "publication": {
    "decision": "EDITORIAL_ANONYMOUS_CANDIDATE_APPROVED",
    "humanReviewed": true,
    "noPrivateDetailsChecked": true,
    "publicSharingChosen": true,
    "evidenceIndependentlyVerified": false,
    "reviewedAt": "ISO 8601 timestamp"
  }
}
\`\`\`

The placeholder \`"..." \` above describes a schema position: it is **not** valid input or a real sample submission. The review metadata is a human assertion, not a cryptographic signature or proof of action. A pull request review and operator-managed access remain necessary.

Run \`node scripts/build-reviewed-return-graph.mjs\` to project the static \`public/town/returns.json\` and \`returns-graph.json\`. CI validates the output with the **native Free Graph owner**. Do not equate editorial publication of a self-report with a completed act of cooperation. Independent verification is a distinct future system.
