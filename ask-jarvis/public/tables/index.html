The host link is a bearer credential. Anybody with it can moderate or delete network contributions. Never send it as an invitation. Save the receipt yourself: this prototype does not recover lost keys or store them in your browser between visits.

THE TABLE'S SUBMISSIONS

This network ledger records submissions, not proof of a real gathering. Guest entries require host review; a host can hide entries.

WITHDRAW MY CONTRIBUTION.

A successful submission gives you a one-time withdrawal receipt. Save it. Enter its note ID and secret code below if you want to remove your contribution from this table. The network doesn't store the code in plaintext.

Withdrawal requires the private code provided on submission. No account is required.

This is an independent Abundent ledger, not an official organizer network or a public directory. No automatic invitations, RSVPs, attendee verification, emails, or data sharing with partner organizations. You choose the circle, the words, and whether to submit anything at all.

7 DAYS IS A RHYTHM, NOT A REQUIREMENT.

Move the date. Change the host. Branch into several circles. Or let a table end. Nobody becomes a member by receiving a link, and nobody owes the next meeting.
