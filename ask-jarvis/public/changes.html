Decisions that persist

Create a public review issue for a specific candidate. A reviewer with GitHub repository write access opens the comparison and records a decision in an issue comment. GitHub stores the identity and comment; an automated gate publishes the decision in an append-only journal. Submitting an issue does not authorize or approve anything.

Repository reviewers comment one command: /jarvis-review HOLD, /jarvis-review NEEDS_EVIDENCE, /jarvis-review SOURCE_CHANGE_REVIEWED, or /jarvis-review DISMISS. GitHub authentication is required. Do not put private names, addresses, case histories, or sensitive material in public issues.
