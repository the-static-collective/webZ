## Truthful execution boundary
The page currently performs bounded read-only source lookup with deterministic classification, per-source SHA-256, a printable local question-card and visible receipt statuses. It does not invoke native CANNON, OpenManus, ELF or JAR;VIS worker execution; it does not directly contact a community partner. The deployed Vercel adapter is a temporary runtime for the Cloudflare-first vision. The Cloudflare Worker has source files but has **not** been deployed. Any broader public campaign should review rate limits and privacy practices first.
