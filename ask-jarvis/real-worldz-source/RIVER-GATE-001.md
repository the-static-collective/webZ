## Interface boundary
The only first-party data are public location reference cards and fixed learning invitations. User may import their existing *fictional* Willow Run game as a preference hint, but no fictional history becomes a real activity record, rank, environmental observation, or pledge. Any user-entered on-site note is labeled private/self-reported/unverified and offered only for LOCAL download. The optional portable proposal contains only fixed, pre-reviewed prompt text + public reference URL; no typed note, user identity, coordinates of a home, phone/email, measured result, or environmental-effect statement. No account, location permission, outbound sync or environmental data import.

## Permission gates
- Public park existence != currently open trail section; construction and closures require real-time confirmation before travel.
- Park access != permission for cleanup, disturbing habitat, collecting waste/materials, directing volunteers, operating scientific sampling equipment, or entering water.
- Actual stewardship, work, photographs or scientific monitoring require source/land steward permission, qualified field review, safe procedures and independent verification.
- The first three "real-world" ways in are **learn from a public source, draft a non-identifying question, and optionally write a personal local reflection**. There is no active quest assignment and no human-confirmed deed.
- No sponsors or partners are claimed. Link-click is NOT consent, cooperation or fulfillment.
