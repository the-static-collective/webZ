# COUNCIL-008 — Find the missing ingredient

**Status:** protected Vercel Preview experiment; not production, not an autonomous agent. No real organization, steward, grant, venue, food stock or volunteer is enrolled by this feature.

## Why this exists

An answer such as "hold a food-and-music table" can be plausible but generic. The useful question is: **what one particular fact or voluntary commitment must become real before a particular small experiment becomes justified?**

JAR reads the original three fixed public project documents and hashes their bytes. COUNCIL-008 *also* inspects three independently owned source constitutions at pinned exact commits:
- **ALEX.2** `7d116b716df82ee2379b399d90936d2fc01b7b16`: separate sources, readings, interpretations, claims and receipts.
- **3rdi** `e631167a04c6bd1bf95c62cbe5a415994ebb8134`: distinguish occurrence, availability, attention role and relevance; the projection is not authority.
- **LOADOUT** `1adcb3d82f736f3ca8329c3c1d0d9eba398d49ee`: select the minimum sufficient world, fence effects and refuse silent authority expansion.

These are **read-only excerpts of repository README files**, not live invocation of those Python tools, AI research agents, host adapters or an authenticated resource manager. Their presence proves no current deployment or human agreement.

## Actual two-pass experimental workflow

1. Someone asks a bounded public-safe question and receives the original verifiable JAR card.
2. On a *second, clearly disclosed click*, JAR independently inspects the 3 pinned constitutional READMEs. Missing/unavailable documents are explicitly marked.
3. **Groq GPT-OSS 120B (scout)** receives the question, bounded observed excerpts and reference IDs. It must identify ONE missing ingredient, cite specific inspected source IDs only when supported, and propose a non-effectful first human check.
4. **Gemini Flash-Lite (critic)** receives the same bounded inspected notes plus Groq's parsed/validated proposal. It challenges evidence, availability, causal leaps and unearned authority, returning HOLD / REVISE / DRAFT_REVIEW plus one smallest verification.
5. The result keeps both perspectives and the disagreement rather than fabricating a model consensus. The whole bounded observation carries a separately verifiable **unsigned** receipt; the browser compares exact source identities and hashes to the original local card. Any HOLD remains a HOLD, not a claimed execution.

**Maximum two model calls per explicit click; no automatic retry, free-plan-to-paid upgrade, fallback to NVIDIA trial, dynamic routing, generic external URLs, tool use or project execution.** A failure during scout stops before critic and returns HOLD; a failure during critic returns PARTIAL_HOLD with no accepted result. All provider keys remain server-side.

All inputs to providers are public-safe questions and a small set of inspected public documents. Providers may log/retain the prompts. Do **not** type private names, phone numbers, client records, custody/health information, or secrets into this protected test.
