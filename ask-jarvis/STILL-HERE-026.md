The STILL HERE timeline now records two separate clocks: **when an event reportedly happened** and **when its information first became available to this observer**. Missing and future source encounters are withheld explicitly.

The page's `ghostCut()` adapter exports a native-contract-compatible JSON candidate:
- knows only `local-event-N` and `local:timeline:N` pseudoreferences;
- explicitly does **not** reproduce personal allegations, quotes, carrier bytes, witness names or raw event narrative;
- marks `contact:false`, because the page cannot attest to external original-source contact;
- remains `projection_only` with no gate admission;
- is **not validated in the browser**. The recipient must run native `blackstar` on their own device.

The PDF/print/text one-page working context stays a separate user-controlled local export and does not get silently attached to Ghost Cut or GRAFT.

## An invitation chain that does not disclose the story

STILL HERE now generates an explicit role invitation (20 minutes listening / one phone call / one resource / short chronology review / ordinary errand). The initiator chooses a 24h, 7-day or open timeframe and can copy or choose the native mobile share sheet. Only a generic bounded task crosses the phone's share sheet. **No event narrative is included.**

The prospective helper can compose four equally permitted replies: can, smaller, ask permission to recruit somebody else, or decline. The relay never automatically enrolls, posts, forwards personal details or sends to other contacts. A third-party intermediary may not be used to evade protective/no-contact restrictions.

This is a **human-initiated invitation chain**, not algorithmic matching, a staffed hotline, or a community-wide shared board. It needs human safeguarding/moderation before any persistent stranger matching is rolled out.

## Failure fences

- `event clock != discovery/contact clock`
- `local summary != source-carrier contact`
- `valid cut != true event`
- `Black Star export != Black Star execution`
- `GRAFT source code != GRAFT intake of private records`
- `invitation draft != delivered message != consent != completed work`
- `a forwarded private story without permission is not a valid chain`

No automatic network calls or browser persistence. Sharing invokes the native OS share sheet only via a dedicated user button. The page uses DOM `textContent`, no URL query/fragment for private data and no inline JavaScript/styles under the existing restrictive CSP. Native ZIP download from public GitHub is explicitly initiated, and public GitHub is never used as a store for case records.

## Tests and limitations

`test/still-here-relay.test.mjs` checks the pin, source clock separation, zero sensitive narrative in the native cut, withheld and prospective source behavior, voluntary replies, and absence of implicit network/storage. The Vercel preview build invokes `npm test`.

Before production: qualified advocate review, accessible Android QA and a careful threat-model review. Authenticated, revocable referrals and a real helper registry require a separate, explicit authorization and operational steward; neither is represented as existing.
