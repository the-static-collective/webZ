# VIS-006 — The librarian and investigator

**Status:** proposed Nemotron-only trial on a feature branch, disabled by default, not promoted to Abundent. This is not an autonomous agent.

## Two passes, two distinct sources of authority

1. **JAR (read-only librarian):** `/api/ask` validates the question, chooses three **fixed commit-pinned public documents**, reads the GitHub bytes, hashes complete observations, and produces the existing deterministic question card or plan. A URL, a document title, a hash, or a plan is not proof of capability or consent.
2. **VIS (experimental investigator):** a visitor explicitly clicks the model button *after* receiving a deterministic return. Only that question, seven subject facets, up to four deterministic ideas, and **up to three 235-character inspected public-source excerpts** can go to an external language-model provider. Never send the full read-only document or account data. The model returns bounded JSON: summary, 1–3 ideas, their source IDs, a reversible first test, remaining unknowns, and a permission check. The server rejects nonexistent source IDs, malformed responses, and attempts to exceed limits.
3. **Return:** a separately hashed, unsigned model proposal is displayed as a distinct result. The browser verifies the receipt and that its deterministic parent is the current question before displaying it. Citations point to inspected source documents; they do not substantiate every claim. The original deterministic return remains unchanged.

## Runtime modes and activation

- **Current Vercel public release:** still `/api/ask`; `/api/investigate` stays disabled unless an operator explicitly sets `JARVIS_AI_ENABLED=1` and configures an AI Gateway bearer token. Server code accepts `AI_GATEWAY_API_KEY` or `VERCEL_OIDC_TOKEN`. The model is pinned to `nvidia/nemotron-3.5-lightning-free`, and the destination is pinned to `https://ai-gateway.vercel.sh/v1/chat/completions`. Never enter bearer tokens in browser fields or commit them.
- **NVIDIA developer evaluation:** The protected Vercel preview also supports `NVIDIA_API_KEY` from NVIDIA Build, targeting the fixed Nemotron Lightning model at `integrate.api.nvidia.com`. Configure it as a server-side Vercel Preview variable; the hosted free endpoint is for development and evaluation, not a public production service. No key is configured yet.
- **Cloudflare Worker:** a Workers AI binding `AI` is declared in Wrangler. Server-side `JARVIS_AI_ENABLED=1` is also required before the model is invoked. The fixed model is `@cf/meta/llama-3.1-8b-instruct`. This is an alternative runtime, **not a claim that Cloudflare has been deployed**.
- **No credentials/binding/flag/verified source:** return HOLD. Do not silently switch to a pretend model, to user-controlled endpoints, or to unverified GitHub documents.

**Important NVIDIA trial restriction:** the free hosted Nemotron endpoint logs prompts and responses for product improvement, forbids personal/confidential/sensitive inputs, and is **trial use only, not permitted for production or business-critical systems**. Consequently, even with gateway verification, this pin must **not be promoted to the public Abundent production model endpoint**. Use it only for manually supervised, protected experiments with fabricated public-safe questions. A production deployment must select a production-licensed alternative (for example paid Nemotron Lightning) and go through the same gates.

**DO NOT enable for public anonymous traffic until:** production-grade per-visitor throttling, per-team spend cap, abuse rules, content-policy review, source prompt-injection evaluation, and gateway/worker usage monitoring are installed and tested. With a public model endpoint, a per-instance in-memory counter is not sufficient rate limiting. A gated team preview or locally provisioned test environment is the appropriate first model trial.

## Security and privacy

The visitor must click to send. The question is not saved in our app database (there is none). A model provider/gateway may independently log or retain request metadata and prompts; do not promise zero retention. Do not submit names, contact info, health data, or private organizational records. The existing email/phone screen is a *basic filter*, not a guarantee that all personal information is blocked. The server allows no dynamic source URL, arbitrary model, function call, external action, grant, public posting, contacts, or payments.

**Inspectable model transcript:** Only the validated answer and bounded source-reference metadata are returned. Neither a successful response nor a receipt implies a partner agreed or a project executed. An unavailable source must not become a fact by model inference.

## Release gates and tests

`npm test` from `ask-jarvis/` (Node 22+) exercises deterministic rules, source failures, new model adapters, receipt tamper checks, nonexistent citations, no-network HOLD, HTML source handoff, and existing game routes. GitHub Actions runs a selected regression set on the PR. The Vercel preview requires a separate smoke check, and real-model quality must be tested by a human against held-out questions and source-injection specimens **before** public activation.

**Admissibility rule:** OBSERVATION ≠ MODEL PROPOSAL ≠ HUMAN CONSENT ≠ ACTION ≠ RECEIPT OF COMPLETED WORK.
