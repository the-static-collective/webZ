THE LANTERN
COMMONS

Two harbors. Two levers. One voluntary festival. A genuine Minecraft world-readback carried through native GHoT—without confusing game victory for real-world authority.

Circuit 004 · Separate empty Java test world only

INVITE → STAGE → TWO GAME SIGNALS → OBSERVE → NATIVE GHOT HASH → FESTIVAL SEAL → HOLD

1 · Prepare

Use your own empty, dedicated Minecraft Java creative server, RCON bound to localhost, and a separate GHoT checkout. Java 26.1.1 requires current hardware and Java; this ZIP does not include Minecraft.

2 · Launch

On Mac: open start-minecraft-foundry-mac.command, inspect it, explicitly type EMPTY_TEST_WORLD, and enter the RCON secret privately in Terminal. Open the local web app.

3 · Plant

In 08 · Minecraft World, stage ten fixed blocks only after collision preflight and your approval. The two harbors have blue and lime markers, lamps, and levers.

4 · Play

Fly to 0 70 0 in your game. Two players can separately flip the two levers (but identities are not authenticated). Both lamps must be lit.

5 · Witness

Press Observe. Abundent queries native Minecraft block state, hashes the observation through genuine GHoT, and records only a game-world HOLD.

6 · Reproduce

With both lamps actually lit, authorize the sea-lantern festival seal. Later, take the reproduction method into another local world by a new operator—without carrying automatic social permission.

Mac Mojave note: the older Mid-2012 MacBook is unlikely to run the current official Java server. Use it as a local operator if compatible Python is available, with the server running on a newer computer through a secure localhost SSH tunnel. Never open RCON publicly.

Read MINECRAFT_004_FIELD_CARD.md for exact prerequisites and the developer test commands. This is a local experimental pilot, not an open multiplayer server or a financial network.
