ABUNDENT CIRCUIT · FIELD EXPERIMENT 003

Two computers.
One verified task.

Prepare a real native GHoT hash crossing between two independent machines—no public backend, no shell access, no account, no false Deed.

Preparation: download the genuine GHoT source separately onto both computers and have Python 3.10+ installed. Use your own trusted private Wi-Fi. Test phrases only: the remote device stores task text.

Computer B · WORKER

  1. Unzip this kit and double-click start-ghot-lan-worker-mac.command.
  2. Choose the folder containing ghot/reference_node.py.
  3. Type YES to deliberately open a LAN listener on port 7789.
  4. Copy the printed private IP address, 64-character pairing key, and note the GHoT node ID.
  5. Leave the terminal open for the experiment.

Computer A · OPERATOR

  1. Double-click start-native-ghot-mac.command.
  2. Open http://127.0.0.1:8878/ if the browser does not open automatically.
  3. Choose a harbor and tap 06 · Compute.
  4. Enter http://B_PRIVATE_IP:7789 and paste B's pairing key. Press Pair.
  5. Run ONE TABLE → ONE OTHER COMPUTER through the remote native GHoT form.

What counts as success?

A shows a NATIVE GHOT / LAN WORKER record with the same node ID that B printed. B has written native ghot.task and ghot.receipt records under its private GHoT home. A's SHA-256 digest matches the native output. Unpair, close the terminals, and confirm no unnecessary open listener remains.

A local automated CI test proves two processes, not two physical computers. Your field run is the missing independent hardware proof. Keep the trial record private unless you choose to share a redacted result.
