01A / AUDIUS PUBLIC CATALOG · EXPLICIT OPERATOR LOOKUP

Another independent listening territory.

On a Node.js 22+ desktop terminal, run npm run music:audius -- search "artist or track" or npm run music:audius -- track D7KyD. Redirect the resulting JSON to a local file, choose Audius above, then import that file. The external lookup is initiated only by you; no page fetch, background polling, account credentials, audio download or implied publishing rights.

For our first real capsule, import the supplied examples/music-field-004-let-it-find-us.json as Suno. The audio file and its hash stay outside the public source repository.
