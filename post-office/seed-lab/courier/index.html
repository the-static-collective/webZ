STATION A

A · The writer

Start with the one public preface Letter 000. A creates a content-verified parcel with a transit-chain origin note. Export a file, then switch A's browser off. There is no email address or recipient account in the parcel.

B · The traveling Post Office

Import the seed from A, independently verify its contents and origin note, and explicitly save a local HOLD. The parcel is saved in this browser's IndexedDB only after you approve, and it can be reopened after a reload.

C · The new reader

Import a parcel carried by B. C checks the original content and each transit-chain link independently, even while A is offline. Nothing is accepted or rendered before consent.

What this does—and doesn't—prove

Demonstrates separate A, B, and C browser stations, deliberate file handoffs, reproducible transit-note hashing, explicit local persistence, and offline file reconstruction. It does not yet provide trusted author signatures, independent node identity, optical QR transport, discovery, a real network relay, or live peer-to-peer availability.

Hashes detect mismatches but malicious parties can rewrite and rehash unsigned transit notes. Keep the original public seed and independently trusted publisher identity when that becomes available.
