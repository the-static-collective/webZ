Two-reader experiment

Download the seed from reader A. Open reader B in another browser profile or device and import that same file. Both readers independently recompute the hash and should reconstruct the same view for identical dial settings. Then export the one-file HTML page, disconnect from the network, and open it as a local file. This is file handoff, not yet network P2P.

Boundary: SHA-256 checks content consistency, not who authored it. No signing key, P2P transport, email delivery, storage, or automated publishing is issued here. The generated HTML itself is an unsigned projection.
