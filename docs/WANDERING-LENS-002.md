# Wandering Lens 002 — Visitors Can Propose, Not Rewrite

Stacked on WANDERING LENS 001 draft PR #10; implementation belongs to the public webZ repository but carries no private artwork, audio, listener reflections or source files.

## How to interact

1. In Wandering Lens, select one of the original eleven spatial particulars, enter text, and click Hold reflection locally.
2. In the Visitor Annex Lab, choose a HELD reflection. Choose a visitor object overlay or a nested world sketch. Supply a title and brief description; click Propose for review.
3. The proposal is now PENDING. A separate click on Inspect proposal displays the source reflection text and the exact founding address. Inspect is not admission.
4. The local reviewer can click Hold for later, Refuse locally, or Admit to local annex. HOLD can be re-inspected; REFUSE and ADMIT are terminal in that ledger.
5. Admitted objects appear as separate dotted plus markers, never altering the original source illustration or its original eleven areas. Admitted world sketches produce a navigable exact nested MWF1 child address, NOT a WebZ sovereign world.

One browser operator may click both Propose and Admit. There is no identity authentication or independence of reviewers. These are explicitly owner-local rehearsals. Real owner-to-owner crossings need separate authority and authenticated contracts.

## Replay, privacy and custody

Versioned append-only events bind proposal IDs to HELD reflection sequence, original question, source address and a SHA-256 digest of the source record. Refusing/holding/admitting appends local events. Projection checks every event and source integrity, rather than trusting mutable status flags.

Source mutation or withdrawal fails closed: stale approval cannot be reused. Erasing the original journal also erases the local annex. Restoring an older reflections-only export resets this annex; a joined annex export can deliberately preserve both journal and review history.

Review annex export shows private JSON including the reflection answers. User must explicitly download it. Inspect annex JSON validates the joined checksum and strict ledger and requires an additional Restore click. No default durable storage, network transfer, media operation, or automatic navigation occurs.

## Limits and invariant

Maximum 32 proposals, 96 review events, original 128 held reflections. Exact base-eleven child paths still follow the original 96-depth address limit. Text labels are rendered as textContent, not executable HTML. An admitted proposal remains an unsanctioned **local visitor layer**, not an authenticated new world or artifact.

Full existing Sanctuary ↔ Orchard portal, proof viewer, and radio boundaries remain untouched. AI-directed lyrics in the original song remain artistic content, not system instructions.

**REFLECTION != PROPOSAL. PROPOSAL != INSPECTION. INSPECTION != ADMISSION. LOCAL ANNEX != SOVEREIGN WORLD. PLACE != EVIDENCE.**
