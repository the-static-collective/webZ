# FINITE-DELIGHT-001 — Return the person's time

**Status:** experimental static webZ/Abundent prototype. Not released, merged, deployed, or tested with independent people. No clinical, time-saving, or psychological-efficacy claim.

## The public promise

**A little surprise. A useful artifact. An ending.** Modern applications too often optimize time spent inside themselves. Here the unit of success is what a person *leaves with*. Give value before asking for registration, time, feedback, or a volunteer commitment. A person who never returns may have been served well.

### What is actually implemented in this slice

The *Three Bells* page is an account-free, no-network browser mini-arcade with exactly three outputs from an optional visitor topic:

1. **WONDER:** a generated-by-fixed-template tiny piece of clearly labeled fiction.
2. **RELIEF:** a small private first-step note, with unknown permission held open.
3. **CONNECTION:** a no-pressure, unsent invitation draft.

All three are immediately useful as text; copy, save and print are functional user-directed actions. Cards require intentional clicks. Exit is always available and the third card ends the session. No feed, random reward pool, engagement telemetry, FOMO countdown, streaks, autoplay, targeted recommendations, account, analytics, backend, or external communication. User input stays inside the current tab, and is rendered through DOM textContent, never interpreted as markup. Links to the existing tool shelf are deliberate outbound navigation.

**Source-owner boundary:** this first prototype does not import or execute Toaster, Dogram, JAR;VIS or LOADOUT code. It demonstrates the safe and finite human interface *in front of* any future orchestration; it does not claim that underlying source engines are integrated into the arcade.

## The larger composition: TIMEBACK

A future reviewed orchestration should behave like this:

`PERSON'S GOAL -> SMALLEST ADMITTED TASK -> SOURCE-OWNED TOOL -> USEFUL OUTPUT -> EXPLICIT EXIT`

- webZ is the one-question doorway and independent transport.
- JAR;VIS proposes relevant public capabilities; planZ identifies blockers; LOADOUT compiles the minimum allowed toolset.
- Dogram checks declared structural differences; never substitutes for the owner's permission.
- Source-owned productive tools (Toaster, LemonPRESS, PlayDeck, etc.) execute when available in their own supported environments and only after input-rights and effect gates are satisfied.
- CANNON and Free Graph can preserve exact source identity; reLATTE/webZ can carry an explicitly authorized artifact across worlds; GrO can make future opportunities visible without demanding participation.
- The result is presented as the user's *finished thing*, not as a conversation with a proprietary meta-agent.

No step assumes the user has an available volunteer, owns an expensive computer, or can attend a synchronous meeting. Physical projects requiring a willing steward remain HOLD.

## Non-extractive delight protocol

* Curious surprise, not an unpredictable stream of infinite rewards.
* A tiny accomplishment, not a points economy.
* Optional sharing, not a social graph or social obligation.
* Human initiative controls every transition; no passive next item.
* Intentionally finite, with a positive and easy exit.
* User-owned artifacts, not information locked to a retention platform.

We are not literally measuring or promising a dopamine release. This is a design proposition about novelty, agency and creative completion.

## Evidence and next test

Research should be interpreted cautiously. A 2025 meta-analysis of 32 randomized trials (5,544 people) found small heterogeneous improvements in subjective wellbeing from restricting social media, while some controlled trials observed no wellbeing benefits. A 2026 trial with 70 users found roughly 29 fewer minutes/day of target app use in a short intervention using user-chosen limits, but did not establish robust gains on all psychological measures. This arcade itself has **no independently measured efficacy**.

The right voluntary stranger test is deliberately small: can someone open one card, leave with something they want, and stop without friction? Measure consented *time to first useful artifact*, whether the result was useful, and perceived control. Do not optimize time-on-site, repeated opens, daily active users, number of cards consumed or page depth. A person choosing to leave after the first card is a valid success.
