# BRIDGE-ATLAS-002 — The Constellation / Map Scan

**Status: a real public static atlas viewer and candidate trail builder, not a network of enrolled partners or an executable cross-repository orchestrator.**

The portal at `/bridge/atlas/` projects the [Static Collective Living Git Map](https://the-static-collective.gitbook.io/the-static-collective-docs/living-git-map/atlas) into a bounded and searchable source address rack, keeping its owned data and verification boundaries separate.

## Source and freshness
The source [public-index.json](https://github.com/the-static-collective/What-is-the-static-collective-/blob/main/atlas/generated/public-index.json) was captured at **2026-10-28T14:01:15+00:00** and contained 89 public repositories, 2207 branch refs and 1067 open PRs. Editorial shelves came from [the generated GitBook inventory](https://the-static-collective.gitbook.io/the-static-collective-docs/living-git-map/atlas/generated), which is separately maintained. Five existing cross-project relations are recorded as `SOURCE_DECLARED` on their owning README surfaces. Other map entries are **inventory observations only**.

The viewer is a copied *dated public snapshot*, not a live, automatically updated inventory. Default branch is a Git ref, not CANNON-selected canon; a surviving open PR is not accepted code. Some potentially relevant experiments exist on branches only. Absence from the public map is not nonexistence. Read actual repo source at the time of use.

## High-leverage findings
**GHoT is not just a GPU service.** Its owner README documents capability discovery, two-body LAN work, energy-aware scheduling, HOLD/cancel/wake, and failure-aware recomposition. Together with MSyoU's source-pinned GHoT two-process experiment, this suggests an *owner-authorized compute commons* for simulations, music media preparation, research and print kits. It does not establish a deployed public compute pool, physical campus test, remote execution authority or volunteered electricity.

**LOADOUT and CANNON should constrain every attractive composition.** LOADOUT's explicit session/effect fences and CANNON's exact owner-selected version discipline prevent the atlas from treating nearby tools or `main` as permission/canon.

**Free Graph, TranchNode, Project0, Corpus OS, fogGlass and GRAFT** answer different questions about provenance, ambiguity, local admission and source continuity. Their adjacency is a promising reviewed *composition*, not an already running pipeline.

**The cultural layer has physical leverage.** Band Runtime, Static Live, Haunted Toaster/Phonography/Blender, LemonPRESS and the field kits offer ways to explain and carry a human invitation without mistaking media artifacts for actual participation, rights, distribution or service outcomes.

## The next executable crossing
1. Obtain an independently chosen, non-sensitive, real-world need from a willing source steward; no case files or private site addresses.
2. Compose **one** demonstrator via an exact pinned input and owner-approved route; print the proposal before attempting integration.
3. Choose a capability donor only with explicit source commit, scope, compatible license, minimum permitted effect, no secret/data leak and a working test.
4. Require independent destination HOLD / REFUSE / review, then separate task and publication permissions.
5. Distinguish provider acknowledgement, operator report, independent confirmation and verified reusable method.
6. Export a bounded, reviewable receipt only if participants authorize the resulting public text.

The paths do not confer organizational membership, governmental endorsement, machine access, grant eligibility, publication rights, clinical appropriateness or humanitarian-case handling authority.

**Invariant:** `EVERYTHING_COULD_BEAR_ON_SOMETHING != EVERYTHING_IS_IMPLEMENTED_WITH_EVERYTHING`.

## Implementation / verification
`bridge/atlas/atlas.json` is the static network snapshot, and `index.html` + `app.mjs` + `style.css` is the fully local reader. `tests/atlas.test.mjs` verifies exact source population, status types, path references, links and privacy boundaries. The preexisting `apps/build.mjs` already copies all of `bridge/` into the static Abundent bundle; no new Vercel project, backend, API key or DNS change is needed.
