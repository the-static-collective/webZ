# NEEDS-001 — What can we do today?
Status: unmerged experimental webZ local field porch, not a public submission service.

The first browser-local loop lets a person state a non-sensitive need, pledge locally, explicitly accept, self-report and locally confirm. A pure deterministic selector suggests one open candidate (pledge present first, smaller scope second, earlier entry third) but cannot accept or act.

This is an ENTRY DOOR for the existing NanaSpork/Garden Help Slip and Jubilee Campfire need lifecycle, NOT a second shared ledger. Only an unresolved local non-demo need can be exported as Garden's exact fulfillment-envelope/v0 carrier (one qualitative requirement). A human must carry the file to Garden and choose HOLD and any later per-requirement POUR. Garden alone maintains authenticated member-scoped sharing and separate reported versus confirmed receipts. None of this experimental webZ data is synced or published.

Local storage is opt-in. Imported exports are checked for structure and unsigned SHA-256 consistency before explicit restore. This is not authentication. All visitor text is rendered with textContent. No keys, accounts, network writes, payments, automatic routing, shared identity, community feed, moderation, or anti-abuse handling are implemented. Demo specimens are labeled and blocked from Garden export. Do not use this porch for personal or emergency needs.

Manual proof: start with an empty board; open a synthetic need; pledge and accept; record self-report; locally confirm; export an additional unresolved need and inspect the Garden carrier; import it on a trusted NanaSpork test device (must HOLD, not auto-publish). Export board and restore in a second browser; compare recommendation; change a byte to confirm import refusal. Test nested-path service and offline on an actual device. Unit tests do not constitute real-world field proof.

Next gate: separate, consent-based moderated public intake and human review. Implement that only with explicit publication scope and a proven private queue; never expose raw Garden envelopes or weaken Campfire RLS.
