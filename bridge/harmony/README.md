# Harmony Layer — voluntary culture composition

One specific, useful doorway into independently governed tools. People can opt in, decline, adapt, or leave. Neither a software link nor a cultural analogy creates institutional consent.

This directory will host a public-safe, static mission doorway composer, not a registry of members, a new compulsory government, or an automated tool that speaks for organizations.

The code composes from **public project-owned Git sources only**. Private Google Drive originals remain outside this public repository unless separately reviewed and authorized for publication. This introduction does not claim that a local steward, institution, field act, or physical Linux installation has been verified.

**Culture is an overtone, not a takeover. Invitation is not admission. A tool is not an authority.**
