OPERATOR-REVIEWED PATH

From possibility to a real receipt.

1 · VERIFY

Check current application deadline, eligibility, program scope, and official source.

2 · AUTHORIZE

Locate a willing lead, authorized local steward, and appropriate project permissions.

3 · PREPARE

Build the smallest factual demonstration. Share only owner-approved, non-sensitive material.

4 · INVITE

Human inspects an unsent draft. Outbound contact is a separate action, never automatic.

5 · RECEIVE

Record actual reply and independent recipient HOLD / REFUSE / REVIEW; never infer from click counts.

6 · VERIFY RETURN

Distinguish application, acceptance, funding, completed task, report, and independent confirmation.

The desk is static and local-only. No fetch, backend writes, organization profiling, automatic mailing, money movement, status promotions, or cross-repository execution.
